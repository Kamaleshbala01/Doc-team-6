//
// Two kinds of relationships appear in this file:
//   1. Real foreign keys — `Ref:` lines for @ManyToOne / @OneToOne /
//      @ManyToMany associations between entities that live in the SAME
//      service (i.e. an actual FK constraint exists in that service's DB).
//   2. Logical references — plain string columns (e.g. `user_id`,
//      `tournament_id`) that point at another SERVICE's primary key.
//      These are NOT real foreign keys (separate databases, standard
//      microservice practice) and are documented with a `note:` on the

  Note: '''
    11 independently-deployed microservices, each with its own schema/database.
